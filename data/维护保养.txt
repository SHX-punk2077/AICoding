 扫地机器人维护保养指南

 一、日常维护

    1. 尘盒清理
频率：每次使用后（无自动集尘）或APP提示时

操作步骤：
1. 取出尘盒，打开盖子
2. 倒出垃圾，可用小刷子清理角落
3. 用清水冲洗尘盒（注意滤网不可水洗的型号）
4. 彻底晾干后装回

注意事项：
不要使用热水冲洗，防止变形
清洗后务必晾干，潮湿会损坏风机
检查尘盒密封条是否完好

    2. 拖布维护
频率：每次拖地后

操作步骤（可清洗拖布）：
1. 拆下拖布
2. 用清水冲洗，可加少量中性清洁剂
3. 搓洗至干净
4. 彻底晾干或烘干后存放

注意事项：
不要使用漂白剂或强力消毒液
潮湿拖布容易发霉发臭
建议2-3个月更换新拖布

    3. 滤网保养
频率：每周清理，2-3个月更换

操作步骤（可水洗滤网）：
1. 取出滤网，轻拍去除灰尘
2. 用清水冲洗（部分滤网不可水洗，请确认）
3. 彻底晾干24-48小时
4. 装回使用

注意事项：
未彻底晾干的滤网会导致风机损坏
水洗滤网寿命会缩短
不可水洗滤网只能用吸尘器或刷子清洁

二、每周维护

    1. 滚刷清理
操作步骤：
1. 拆下滚刷盖板
2. 取出滚刷
3. 用附赠的清理工具或剪刀清理缠绕的毛发
4. 检查滚刷胶条和毛刷是否磨损
5. 清理滚刷仓内的残留物
6. 装回滚刷和盖板

注意事项：
毛发缠绕严重时可用清水冲洗滚刷
胶条磨损后清扫效果下降，需更换
滚刷轴承处可加少量润滑油

    2. 边刷维护
操作步骤：
1. 拆下边刷（注意左右区别）
2. 清理轴上的缠绕毛发
3. 检查边刷是否变形、开裂
4. 清理边刷安装座
5. 装回边刷

注意事项：
边刷变形会导致清扫盲区
边刷磨损严重时清扫效果下降
左右边刷不能装反

    3. 万向轮清理
操作步骤：
1. 拆下万向轮（部分机型可拆卸）
2. 清理轮轴上的毛发缠绕
3. 用湿布清洁轮子表面
4. 装回万向轮

注意事项：
 万向轮卡滞会导致导航异常
 检查万向轮转动是否灵活

    4. 传感器清洁
需要清洁的传感器：
悬崖传感器（底部，通常4-6个）
红外传感器（前部）
充电触点
激光雷达表面（如有）
摄像头（视觉导航机型）

清洁方法：
使用干净软布擦拭
避免使用湿布，防止液体渗入
不要使用尖锐物体刮擦

三、每月维护

    1. 深度清洁机器
操作步骤：
1. 拆下所有可拆卸部件（尘盒、滚刷、边刷、拖布、水箱）
2. 用软毛刷清理机身缝隙
3. 用湿布擦拭机身
4. 清理驱动轮花纹内的杂物
5. 清洁充电触点（可用橡皮擦）
6. 组装所有部件

    2. 基站清洁（如有）
操作步骤：
1. 断开电源
2. 取出清水箱和污水箱，清洗晾干
3. 清洁清洗盘：取出滤网，冲洗清洗盘
4. 用湿布擦拭基站内部
5. 检查集尘通道是否堵塞
6. 清洁基站充电触点

注意事项：
基站底部易积水，需擦干
清洗盘滤网堵塞会影响清洗效果
定期检查污水箱密封圈

  3. 耗材检查
边刷：检查是否变形、磨损，3-6个月更换
滚刷：检查胶条磨损，6-12个月更换
滤网：检查是否脏污、破损，2-3个月更换
拖布：检查是否变硬、破损，2-3个月更换
电池：检查续航时间，2-3年更换

四、季度维护

    1. 激光雷达保养
操作步骤：
1. 清洁激光雷达表面
2. 检查激光雷达旋转是否顺畅
3. 用软毛刷清理雷达缝隙灰尘
4. 检查雷达顶部是否有异物

注意事项：
激光雷达故障会导致导航异常
不要自行拆解激光雷达
