   扫地机器人故障排除指南

     一、电源与充电故障

       问题1：机器人无法开机
可能原因：
电池电量耗尽
电池损坏
主板故障

解决方法：
1. 连接充电座充电15-30分钟后重试
2. 检查充电座是否通电（指示灯亮）
3. 清洁机器人和充电座的金属触点
4. 长按电源键10秒强制重启
5. 如仍无法开机，联系售后

       问题2：无法充电/充不进电
可能原因：
充电座位置不当
触点氧化或脏污
电池老化
充电座故障

解决方法：
1. 将充电座靠墙放置，前方1.5米、左右0.5米无障碍物
2. 用干布或橡皮擦清洁机器人和充电座金属触点
3. 检查充电座电源线是否插紧
4. 尝试更换充电座或电源适配器
5. 电池寿命通常2-3年，到期需更换

       问题3：充电慢
可能原因：
环境温度过低或过高（最佳充电温度5-40℃）
电池老化
使用非原装充电器

解决方法：
1. 在室温环境下充电
2. 检查电池健康状态（APP可查看）
3. 使用原装充电配件

       问题4：耗电快/续航短
可能原因：
电池老化
吸力设置过高
滚刷或轮子阻力大
频繁返回充电座

解决方法：
1. 检查电池健康度，考虑更换电池
2. 根据地面情况调整吸力
3. 清理滚刷、边刷、轮子上的缠绕物
4. 检查地图规划是否合理

     二、移动与导航故障

       问题5：找不到充电座
可能原因：
充电座位置变动
充电座被遮挡
激光雷达/视觉传感器故障
地图丢失

解决方法：
1. 将充电座放回原位并确保前方开阔
2. 清洁激光雷达或摄像头
3. 手动将机器人放回充电座充电
4. 在APP中重置地图，重新建图

       问题6：乱跑/路线混乱
可能原因：
传感器脏污
激光雷达/摄像头故障
地面反光过强
悬崖传感器被触发

解决方法：
1. 清洁所有传感器（激光雷达、悬崖传感器、红外传感器）
2. 检查激光雷达是否正常旋转
3. 避免地面有大面积镜面反射
4. 检查悬崖传感器是否有异物遮挡

       问题7：卡住不动
可能原因：
被电线、流苏等缠绕
门槛过高无法跨越
进入狭窄区域无法脱困
轮子打滑

解决方法：
1. 移除卡住位置的障碍物
2. 在APP中标记卡住区域并设置禁区
3. 检查轮子是否缠绕毛发
4. 对于门槛过高，安装斜坡辅助

       问题8：无法爬坡/门槛过不去
可能原因：
门槛高度超过机器越障能力（通常1.5-2cm）
轮子磨损
驱动轮故障

解决方法：
1. 测量门槛高度，确认是否在机器能力范围内
2. 安装门槛斜坡或购买专用门槛条
3. 检查轮子花纹是否磨损严重
4. 清洁轮子上的油污，增加摩擦力

       问题9：从楼梯跌落风险
可能原因：
悬崖传感器脏污
悬崖传感器故障
地面颜色过深吸光

解决方法：
1. 定期清洁悬崖传感器
2. 测试悬崖传感器功能（放在桌边观察是否后退）
3. 在APP中设置虚拟墙或禁区
4. 深色地毯可能导致误判，可贴反光条辅助

       问题10：地图丢失/建图失败
可能原因：
机器人被搬动
充电座位置变化
传感器故障
环境变化过大

解决方法：
1. 首次建图时不要搬动机器人
2. 在APP中恢复地图备份（如有）
3. 删除旧地图，重新建图
4. 建图时确保光线充足（视觉导航机型）

     三、清洁功能故障

       问题11：吸力变小
可能原因：
尘盒已满
滤网堵塞
滚刷缠绕
吸口堵塞
风机故障

解决方法：
1. 清理尘盒
2. 清洗或更换滤网（彻底晾干）
3. 清理滚刷上的毛发缠绕
4. 检查吸口是否有异物堵塞
5. 如风机异响或无声，需维修

       问题12：滚刷不转
可能原因：
毛发缠绕卡死
滚刷盖未安装到位
驱动电机故障

解决方法：
1. 拆下滚刷清理缠绕物
2. 检查滚刷盖是否卡扣到位
3. 手动转动滚刷检查是否顺畅
4. 如电机故障，需更换

       问题13：边刷不转
可能原因：
毛发缠绕
边刷磨损变形
电机故障

解决方法：
1. 清理边刷轴上的缠绕毛发
2. 检查边刷是否变形，必要时更换
3. 按压边刷确保安装到位

       问题14：有异响/噪音过大
可能原因：
滚刷或边刷缠绕异物
吸入了硬物
风机进异物
轮子故障

解决方法：
1. 清理滚刷、边刷、万向轮上的缠绕物
2. 检查吸口是否有硬物卡住
3. 清理尘盒和滤网
4. 检查驱动轮是否顺畅转动

       问题15：清扫不干净/留垃圾
可能原因：
吸力设置过低
尘盒已满
滚刷磨损
边刷变形
规划漏扫

解决方法：
1. 适当调高吸力
2. 及时清理尘盒
3. 检查滚刷胶条是否磨损，更换滚刷
4. 检查边刷长度是否足够，更换边刷
5. 检查地图是否完整，补充清扫

     四、拖地功能故障

       问题16：不出水/出水少
可能原因：
水箱缺水
出水孔堵塞
水泵故障
电控水箱接触不良

解决方法：
1. 加满水箱
2. 用针疏通出水孔
3. 检查水箱是否安装到位
4. 清洁水箱和机器连接处的金属触点
5. 清洗水箱，防止杂质堵塞

       问题17：出水过多/漏水
可能原因：
水箱未安装到位
水箱破裂
密封圈老化
电控水箱失控

解决方法：
1. 重新安装水箱，确保卡紧
2. 检查水箱是否有裂纹
3. 检查密封圈是否完好
4. 在APP中调低出水量设置
5. 如持续漏水，需更换水箱

       问题18：拖布不转（旋转拖布机型）
可能原因：
拖布安装不到位
拖布支架卡滞
驱动电机故障

解决方法：
1. 检查拖布是否安装到位
2. 清理拖布支架上的缠绕物
3. 手动转动拖布检查是否顺畅
4. 检查电机连接是否正常

       问题19：拖地后地面有水痕
可能原因：
出水量过大
拖布脏污
拖布磨损
地面不平

解决方法：
1. 调低出水量设置
2. 清洗或更换拖布
3. 检查拖布是否均匀湿润
4. 选择深度拖地模式增加清洁次数

       问题20：拖布发臭
可能原因：
拖布未及时清洗
未烘干或晾干
水箱/污水箱未清理
使用了变质清洁液

解决方法：
1. 及时清洗拖布并彻底烘干
2. 清洁清水箱和污水箱
3. 使用抗菌拖布或添加抗菌剂
4. 定期清洗基站底盘
5. 开启拖布烘干功能

     五、基站故障

       问题21：机器人无法进出基站
可能原因：
基站前方有障碍物
基站防滑垫移位
机器人轮子打滑
基站斜坡脏污

解决方法：
1. 确保基站前方1米无障碍
2. 检查防滑垫是否平整
3. 清洁机器人轮子和基站斜坡
4. 清洁基站的充电/定位传感器

       问题22：自动集尘失败
可能原因：
集尘袋已满
集尘通道堵塞
尘盒盖未关好
风机故障

解决方法：
1. 更换集尘袋
2. 检查集尘通道是否有异物堵塞
3. 确保机器人尘盒盖关闭到位
4. 清洁集尘口的密封圈

       问题23：自动洗拖布失败
可能原因：
清水箱缺水
污水箱已满
清洗盘堵塞
水泵故障

解决方法：
1. 加满清水箱
2. 清空污水箱
3. 清洁清洗盘的滤网和刮条
4. 检查水路是否通畅

       问题24：基站漏水
可能原因：
清水箱/污水箱未安装到位
水箱破裂
管路连接松动
密封圈老化

解决方法：
1. 重新安装水箱，确保卡紧
2. 检查水箱是否有裂纹
3. 检查基站底部是否有积水
4. 联系售后维修

       问题25：基站有异味
可能原因：
污水箱未及时清理
清洗盘积垢
拖布发霉
集尘袋更换不及时

解决方法：
1. 清空并清洗污水箱
2. 清洁基站清洗盘和滤网
3. 清洗或更换拖布
4. 定期更换集尘袋
5. 使用基站清洁剂进行深度清洁

     六、APP与连接故障

       问题26：无法连接Wi-Fi
可能原因：
路由器设置问题
机器人不支持5G Wi-Fi
密码错误
路由器信号弱

解决方法：
1. 确保机器人仅支持2.4G Wi-Fi
2. 检查路由器是否开启2.4G频段
3. 确认Wi-Fi密码正确
4. 将机器人和手机靠近路由器
5. 关闭路由器MAC地址过滤

       问题27：APP无法控制机器人
可能原因：
机器人与服务器断开
路由器网络故障
机器人离线

解决方法：
1. 检查路由器网络是否正常
2. 重启机器人和路由器
3. 检查机器人是否处于待机状态
4. 重新登录APP账号

       问题28：地图不同步/异常
可能原因：
网络延迟
机器人被搬动
地图数据损坏

解决方法：
1. 检查网络连接
2. 在APP中刷新地图
3. 恢复备份地图（如有）
4. 重新建图

       问题29：固件升级失败
可能原因：
网络不稳定
电量不足
机器人不在充电座

解决方法：
1. 确保Wi-Fi信号稳定
2. 保持电量在30%以上
3. 将机器人放回充电座后再升级
4. 升级过程中不要断电或搬动机器人

       问题30：推送通知收不到
可能原因：
手机通知权限未开启
APP后台运行限制
消息推送服务异常

解决方法：
1. 在手机设置中开启APP通知权限
2. 允许APP后台运行
3. 检查APP内消息设置
4. 重启APP或手机

     七、传感器故障

       问题31：悬崖传感器误报
可能原因：
传感器脏污
深色地面吸光
地面反光过强
传感器故障

解决方法：
1. 清洁悬崖传感器
2. 在深色地板上贴白色胶带辅助
3. 避免地面有大面积镜面反射
4. 传感器故障需更换

       问题32：激光雷达不转/故障
可能原因：
激光头脏污
异物卡住
电机故障

解决方法：
1. 清洁激光雷达表面
2. 检查是否有异物卡住旋转部分
3. 重启机器人
4. 如仍不转，需更换激光雷达

       问题33：视觉导航摄像头模糊
可能原因：
镜头脏污
光线不足
摄像头故障

解决方法：
1. 用软布清洁摄像头
2. 增加环境光线
3. 避免摄像头直对强光

       问题34：碰撞传感器失灵
可能原因：
缓冲器卡滞
传感器脏污
弹簧失效

解决方法：
1. 检查缓冲器是否能自由活动
2. 清理缓冲器缝隙的灰尘
3. 手动按压缓冲器检查回弹

       问题35：陀螺仪/IMU故障
可能原因：
碰撞导致损坏
主板故障

解决方法：
1. 重启机器人
2. 机器人表现（不走直线、打转）需专业维修

     九、定期维护建议

       每次使用后
清理尘盒（如无自动集尘）
检查拖布是否需要清洗

     每周维护
清理滚刷上的毛发
清理边刷缠绕物
清洁悬崖传感器
清理万向轮

     每月维护
清洗滤网（彻底晾干）
清洁充电触点
检查边刷磨损情况
清洁基站底盘（如有）

     每季度维护
更换边刷
检查滚刷磨损
清洁激光雷达
深度清洁水箱

     每半年维护
更换滤网
更换拖布
检查电池健康度
清洁内部风道（专业人员）
